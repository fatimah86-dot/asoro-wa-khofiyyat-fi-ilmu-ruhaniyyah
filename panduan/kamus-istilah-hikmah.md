# 📚 KAMUS ISTILAH FALAK & HIKMAH

> **Aturan pakai:** istilah di bawah ini **JANGAN diterjemah fusha bebas**. Beri catatan **"Istilah Falak/Hikmah"** dan biarkan lafadz aslinya.
> Prinsip: **المحافظة على القديم الصالح** — *Al-Muhafazhatu 'ala al-Qadimi as-Shalih*.

## ⚠️ G. KATA YANG SERING SALAH DITERJEMAH

| Arab | JANGAN diterjemah | TERJEMAH/ CATATAN yang benar |
|---|---|---|
| **وفق** | "persetujuan/kesesuaian" (fusha) | **Wafaq** — Istilah Hikmah |
| **خاتم** | "penutup" | **Khatam** — Istilah Hikmah (cincin rajah) |
| **خادم** | "pelayan/tukang" | **Khodam** — Istilah Hikmah |
| **توكيل** | "memberi kuasa (hukum)" | **Taukik** — Istilah Hikmah |
| **عزيمة** | "kemauan kuat" | **Azimah** — Istilah Hikmah (mantra seruan) |
| **بخور** | "dupa biasa" | **Bakhur** — Istilah Hikmah |
| **زحل** | "Saturnus" saja | **Zuhal** — Istilah Falak |
| **مشتري** | "pembeli" ❌❌ | **Musytari** — Istilah Falak (Jupiter). **Bukan "pembeli"!** |
| **عطارد** | "pensil/pena" ❌ | **'Utharid** — Istilah Falak (Merkurius) |
| **ساعة** | "jam 60 menit" | **Sa'ah** — Istilah Falak (jam planet) |
| **رصد** | "pengamatan" | **Rashad** — Istilah Hikmah (penjagaan bintang) |
| **حجاب** | "hijab/tabir kain" | **Hijab** — Istilah Hikmah (rajah pelindung) |

📌 **Catatan paling penting:** **مشتري** kalau diterjemah "pembeli" akan **hancur total** maknanya. Dalam kitab hikmah selalu = **Jupiter / Musytari**.
