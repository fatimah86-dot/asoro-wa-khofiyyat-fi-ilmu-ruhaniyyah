# 🃏 KARTU SAKU — 10 LANGKAH USTADZ YOAD

> Print & tempel di depan kitab. Urut, jangan dilompati.

| # | Langkah | Yang ditulis |
|---|---|---|
| **1** | **Jenis Kata** | Isim (ada ال) atau Fi'il → cari akar |
| **2** | **Akar Kata** | Madhi – Mudhari' – Mashdar. Bedakan **makna fi'il** vs **mashdar** |
| **3** | **Mubtada' Marfu'** | `مُبْتَدَأٌ مَرْفُوعٌ بِالضَّمَّةِ` |
| **4** | **Khobar Muqoddam** | Cek pola dulu! `عَلَيْهِ` = خَبَرٌ مُقَدَّمٌ · `أَنْ يَشْكُرَ` = مُبْتَدَأٌ مُؤَخَّرٌ · seluruh jumlah = خَبَرٌ لِ "العَبْدِ" |
| **5** | **Huruf An** | `أَنۡ : حَرْفُ مَصْدَرٍ وَنَصْبٍ` → menasabkan mudhari' |
| **6** | **Fi'il Mudhari'** | **A. Marfu'** (يُنْجِي، يُهْلِكُ) wazan أَفْعَلَ–يُفْعِلُ · نَجَا يَنْجُو = lazim, أَنْجَى يُنْجِي = muta'addi · **B. Mansub** (يَشْكُرَ) `فِعْلٌ مُضَارِعٌ مَنْصُوبٌ بِالفَتْحَةِ`, fa'il dhomir mustatir |
| **7** | **Maf'ul Bih** | `مَفْعُولٌ بِهِ مَنْصُوبٌ بِالفَتْحَةِ` (الله) · `ضَمِيرٌ مُتَّصِلٌ فِي مَحَلِّ نَصْبٍ مَفْعُولٌ بِهِ` (هُ) |
| **8** | **Huruf Athaf** | `وَ : حَرْفُ عَطْفٍ` = dan |
| **9** | **Dhorof Zaman** | `دَائِمًا : ظَرْفُ زَمَانٍ مَنْصُوبٌ بِالفَتْحَةِ` = di setiap waktu |
| **10** | **Jar Majrur** | `عَلَى` حَرْفُ جَرٍّ · `كُلِّ` مَجْرُورٌ وَهُوَ مُضَافٌ · `حَالٍ` مُضَافٌ إِلَيْهِ مَجْرُورٌ بِالكَسْرَةِ |
